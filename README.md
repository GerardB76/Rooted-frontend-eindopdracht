# Frontend-eindopdracht over systemisch werk

Dit opleidingsproject wordt een webapplicatie voor een freelancer die informatie en inspiratie over systemisch werk aanbiedt. De applicatie is nog niet gebouwd. We werken eerst de opdracht, functionaliteiten en ontwerpen uit.

## Inhoud

- [Projectidee](#projectidee)
- [Wegwijzer](#wegwijzer)
- [Installatiehandleiding in voorbereiding](#installatiehandleiding-in-voorbereiding)

## Projectidee

De vier uitgewerkte kernfunctionaliteiten zijn registratie/inloggen, blogs vinden en lezen, boeken bekijken en favoriete boeken beheren. Tarieven downloaden blijft een aanvullende functie. Gepland zijn JavaScript, React, React Context, React Router, eigen CSS met Flexbox en de NOVI Dynamic API. De React-applicatie is nog niet gebouwd.
